# spoolbook v0.1.7 — Recommend page retired, SvelteKit frontend in progress

**Released**: 2026-08-14

---

## Highlights

- **Recommend page removed** (`Spoolbook.Web`, both apps' nav): the standalone "recommend a profile" page is gone — the same best-matching-profile suggestion already runs inline when you start a print (project → plate → auto-suggested profile), so the separate page was a redundant hop.
- **Printer control now respects live print state**: Pause/Resume/Stop on a printer card only enable when a print is actually running/paused (previously just gated on the MQTT connection), and the Print button disables while a print is in progress — reads the printer's live `gcode_state` over the same MQTT feed as telemetry.
- **SvelteKit frontend migration in progress**: a parallel `spoolbook-web-svelte` app (SvelteKit + shadcn-svelte + Tailwind v4) is being built alongside the existing Blazor Server UI, backed by a new JSON API (`Spoolbook.Web/Api`). Not yet the default — still dev-only behind a Vite proxy, no production hosting adapter chosen yet — but all 8 page slices (Printers, Home, Filaments, Spools, Prints, Profiles, Settings, plus the now-inline Recommend flow) are ported and passing build/typecheck.

## Upgrading

No schema changes. No action needed — existing installs pick this up on next deploy/restart.
