# spoolbook v0.1.7 — Blazor Server retired, SvelteKit is now the web UI

**Released**: 2026-08-14

---

## Highlights

- **Blazor Server retired, SvelteKit is now `Spoolbook.Web`'s UI**: the parallel `spoolbook-web-svelte` app (SvelteKit + shadcn-svelte + Tailwind v4, backed by a new JSON API under `Spoolbook.Web/Api`) is no longer a dev-only preview — every Blazor `.razor` page is deleted, and `Spoolbook.Web` now serves the Svelte static build (`adapter-static`, SPA fallback for client-side routes) directly. Desktop-app retirement (stripping the Avalonia UI out of `Spoolbook.Desktop`, keeping it only as the shared domain layer until a planned Rust backend port replaces it) is next.
- **Recommend page removed** (both apps' nav): the standalone "recommend a profile" page is gone — the same best-matching-profile suggestion already runs inline when you start a print (project → plate → auto-suggested profile), so the separate page was a redundant hop.
- **Printer control now respects live print state**: Pause/Resume/Stop on a printer card only enable when a print is actually running/paused (previously just gated on the MQTT connection), and the Print button disables while a print is in progress — reads the printer's live `gcode_state` over the same MQTT feed as telemetry.
- **Printer card shows the real product photo** (P1S/P2S chassis) instead of a generic icon, and list pages (Prints, Filaments) got shadcn Pagination instead of plain Prev/Next buttons.

## Upgrading

No schema changes. `spoolbook-web-svelte/build/` is gitignored (a build artifact) — a deploy now needs `npm run build` inside `spoolbook-web-svelte` before restarting `Spoolbook.Web`, or it has nothing to serve.
