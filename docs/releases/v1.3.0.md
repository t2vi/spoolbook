# spoolbook v1.3.0 — bed photo, weather graph, mid-print telemetry charts

**Released**: 2026-08-26

## Highlights

- **A bed photo captures automatically at the end of every print**, regardless of outcome —
  a still frame grabbed off the same live camera relay the Printers page already uses, stored on
  the Print itself. Replaces the `.3mf` plate thumbnail that used to show on the print detail page
  (that's still shown elsewhere) with a photo of what the bed actually looked like when the print
  finished.
- **Outdoor weather over the print, charted hour by hour** — previously only an averaged single
  number, now the full hourly series from the same Open-Meteo call.
- **Mid-print telemetry, charted**: chamber temperature, AMS humidity, and layer progress over
  time, sourced from the printer's own live MQTT reporting during the print (not a new API call —
  this data was already being buffered internally, just never surfaced). Chamber temp and AMS
  humidity are read straight off any abrupt jump in the raw signal — a chamber door opening mid-
  print shows up as a visible spike, not smoothed away.
- **Print detail page reworked** — wider layout, bed photo and print details shown side by side
  instead of stacked full-width, and the three time-series charts moved into tabs.

## Fixed

- **A print could get stuck showing "In Progress" forever** if the backend restarted while it was
  running — the in-memory record of which MQTT job was open didn't survive a restart, so the
  terminal status message that should have closed it out had nothing to match against. Falls back
  to a DB lookup for the still-open job when there's no in-memory match.
- `actual_room_temp_c` — a manual-entry field for a form that hasn't existed since Prints went
  view-only — renamed to `chamber_temp_c` and now auto-snapshotted from the printer's own live
  reading at print-end, same as AMS humidity. Profile recommendation ranking now weighs outdoor
  ambient temperature instead, since chamber temperature is enclosure heat, not room condition.

## Upgrading

No manual migration step — `spoolbook-rs` applies its own schema migrations automatically on
startup. A print that finished before this release gets its mid-print telemetry chart backfilled
automatically the first time the new version starts, provided its raw telemetry was still on
record. Pull the new image and restart:

```sh
docker compose pull && docker compose up -d
```
