# spoolbook v1.2.0 — sidebar nav, project management, real AMS humidity

**Released**: 2026-08-25

## Highlights

- **Sidebar navigation, replacing the top header bar.** Collapsible (icon-only) via a trigger
  button, grouped by workflow (Filaments: List/Spools; Print workflow: Profiles/Prints/Printers/
  Projects), with an account dropdown (avatar, username, sign out) in the footer.
- **A real Projects page**: list, rename, delete (single or bulk), each with a proper confirm
  dialog and a distinct message when delete is blocked because a Print still references it. New
  `/projects/{id}` detail view — plates, file info, mesh hash, version chain, and every Print made
  from it.
- **Prints are now view-only.** The manual "Log a print"/"Edit print" form is gone — a Print's
  real source is the send-to-printer flow now, not hand-entry. `/prints/{id}` and the "Recent
  prints" list under each printer both link to a read-only detail view instead.
- **Re-slicing a project now chains as a new version** instead of piling up near-duplicate rows —
  a real slicer's output is never byte-identical run to run, so the existing content-hash dedup
  could never catch "re-sliced the same project again."
- **Full shadcn-svelte pass**: Tabs (replacing a hand-rolled tab bar in the profile editor),
  Skeleton loading states, InputGroup (units shown inline instead of stuffed into labels),
  filled-background inputs with a real border for actual contrast, and a real app icon (recovered
  from the retired desktop app) as the favicon and sidebar mark.
- **Dates now read `Aug 25, 2026`** everywhere, consistently; table cells drop the time, other
  views keep it.

## Fixed

- **AMS humidity was showing the wrong number.** Bambu's AMS reports two separate humidity
  fields — a coarse 1-5 index (older AMS units, no hygrometer) and a real percentage (newer
  AMS 2 Pro / AMS-HT, what a P2S ships with). The Rust port only ever read the coarse index, so a
  P2S with a real 21% reading showed a bare "5" — which reads exactly like a low, healthy
  percentage when it's actually the *worst* end of the old 1-5 scale. Confirmed against a real
  P2S mid-print, and against maziggy/bambuddy's own field-preference logic. Now shows the real
  percentage when the AMS reports one, with a color cue; falls back to "n/5" only for AMS
  hardware with no hygrometer.

## Upgrading

No manual migration step — `spoolbook-rs` applies its own schema migrations automatically on
startup. Pull the new image and restart:

```sh
docker compose pull && docker compose up -d
```
