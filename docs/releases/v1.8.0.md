# spoolbook v1.8.0 — forms in modals, multi-color swatches

**Released**: 2026-10-17

MINOR: add/edit forms move into modals (a new way to work, with URL-linkable form state), and
the catalog sync gains a capability — keeping color hexes current, multi-color ones included.
Nothing breaking: old `/…/new` and `/…/edit/<id>` links still work.

Spec coverage: 100% of surfaces, 91% of FRs tested (70% at planned layer).

## Changed

- **Every add and edit opens as a modal** over the page you started from — filaments, spools,
  colors, profiles (wide), printers, print outcome, project rename and add, and the Print dialog
  — all in one design: title, scrolling body, Cancel and Save in the footer, full screen on a
  phone. (#249)
- The open form is in the address (`/spools?brand=X&new`, `/profiles?edit=12`), so reload, back
  and shared links reopen it, and the list's filters, sort and page stay as they were. Saving
  closes it and refreshes the list. Old `/…/new` and `/…/edit/<id>` links redirect there. (#249)
- Closing a form with unsaved changes — Cancel, ×, Escape, a click outside, or back — asks first.
  (#249)
- Projects: **Rename** and **+ Add project** open in modals instead of inline. (#249)

## Fixed

- **Multi-color filaments show every color.** `Blue+Red+Purple`, `Black+Gold` and the Rainbow
  family now show one swatch band per color instead of one guessed color (or plain gray). The
  catalog now sends a hex list for them, and the catalog sync updates existing colors to it — but
  never a hex you set yourself on the Colors screen, and never a list you already had. (#251)

## Catalog

The published catalog (spoolbook-filament-sync) now takes most brands from
[SpoolmanDB](https://github.com/Donkie/SpoolmanDB), keeping its own scrapers for Bambu Lab, eSUN,
Hatchbox, Prusament and Colorfabb: Elegoo, SUNLU, Polymaker, Overture, Creality, Protopasta and
Fillamentum are back (GitHub's runners had been rate-limited by their stores), and ~55 more
brands arrive — about 68 in all, real hexes included. Slic3D is no longer in the catalog. Rows
imported before stay; brands that switched source gain new rows alongside the old ones.

## For developers

- Migration `0022` adds `filament_colors.hex_set_by_user` (set by the Colors screen; existing
  hex lists count as set by a person).
- Shared `form-modal.svelte` shell and `lib/form-url.ts` (`?new` / `?edit=<id>`). New e2e
  `forms.e2e.ts`; `unsaved.e2e.ts` now leaves through history and the modal's close.

## Upgrading

No manual step — the migration runs on start. Pull the new image and restart:

```sh
docker compose pull && docker compose up -d
```

Colors update on the next catalog sync (on start at most once a day, or **Sync filament
catalog** in Settings → Filaments).

Closes #249, #251.
