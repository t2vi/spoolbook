# spoolbook v1.8.1 — AMS slot picking, real printer error codes

**Released**: 2026-10-26

PATCH: corrections only. The AMS slot picker and printer error display did the wrong thing; both
now do what they were meant to. No new capability, nothing breaking.

Spec coverage: 99% of surfaces, 91% of FRs tested (70% at planned layer).

## Fixed

- **Couldn't pick an AMS slot in the Print dialog.** Picking any slot (or the matching spool)
  snapped straight back to the first one, so the right spool never stuck and the profile list
  stayed empty. Every live update from the printer, and every spool change, reset the dialog to
  its defaults. A slot now stays picked, and a slot whose material matches exactly one of your
  spools selects that spool and fills its profiles. (#256)
- **Printer errors showed truncated codes with dead links.** Each HMS warning was cut to 8 of
  its 16 hex digits (e.g. `0500-0070` instead of `0500-0300-0002-0070`), the "Bambu
  troubleshooting" link pointed at a wiki page that doesn't exist, and the description came from
  a small hand-written table that mixed up the two kinds of code. Errors now follow Bambu
  Studio:
  - the full code (`07FF-8012` for a print error, `0500-0300-0002-0070` for a warning);
  - Bambu's own description, from the official error list for your printer model (fetched in
    the background, refreshed daily; a generic message until it arrives or if it can't);
  - a link that opens Bambu's page for that exact code on your model.

  Codes Bambu lists without a description — Bambu Studio hides these — now show with an
  **internal** label instead of a misleading message. (#257)
- Docs: getting started said printers are added under Settings → Printers; they're added with
  **+ Add printer** on the Printers page.

## For developers

- New `bambu_error_text.rs`: per-model error dictionary from `e.bambulab.com/query.php`
  (`BAMBU_HMS_URL` overrides it for tests), held in memory. The parser now only emits codes;
  `/live` adds text and links when it builds each snapshot.
- Spec 004 FR-012 amended, FR-014 added, FR-050 states the slot → spool → profile defaults. New
  e2e `printers.e2e.ts`, `printer-errors.e2e.ts`.
- Spec audit 2026-10-26: `specs/COVERAGE.md` rebuilt; gap issues #260–#266.

## Upgrading

No manual step. Pull the new image and restart:

```sh
docker compose pull && docker compose up -d
```

The backend now makes one outbound HTTPS request per printer model per day to
`e.bambulab.com` for error descriptions. Without internet access, errors still show with their
code and a generic message.

Closes #256, #257.
