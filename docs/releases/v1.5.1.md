# spoolbook v1.5.1 — nothing visible without signing in

**Released**: 2026-10-16

Never released on its own: this fix ships in [v1.5.2](v1.5.2.md).

PATCH (hotfix): a security fix, no new capability.

## Security

- **Your notebook was readable by anyone who could reach spoolbook** — on the LAN, or through an
  ingress/reverse proxy — without signing in: dashboard, filaments, spools, profiles, prints,
  printers and projects. Only changes needed a sign-in. Now every page and API read needs a
  session too. Signed out, spoolbook shows only the sign-in page (or the first-run setup page),
  with the version and the Source link. (#208)

The only API routes left open are those needed to sign in or set up the first account, and
`/api/version`.

## Upgrading

No manual step. Pull the new image and restart:

```sh
docker compose pull && docker compose up -d
```

Anything that read the API without signing in (scripts, dashboards) now gets `401` and needs a
session cookie from `POST /api/login`.
