# spoolbook v1.4.0 — data export/import

**Released**: 2026-08-26

## Highlights

- **Migrate data between spoolbook installs from the Settings page** — no shell/Docker access to
  either host needed. Export downloads a zip (filaments, spools, print profiles, printers, prints,
  and their uploaded `.3mf` project files); Import previews per-table counts before you confirm,
  then merges it into the target install rather than replacing it. Filaments, printers, and
  filament colors dedupe against what's already there; everything else — spools, profiles,
  projects, prints — is inserted fresh with every reference remapped to match, so combining data
  accumulated separately on two installs doesn't collide or overwrite either one.

## Fixed

- Uploaded `.3mf` files were stored in the container's temp directory instead of the persistent
  data volume — every redeploy silently lost every project file a print referenced. Now stored
  alongside the database itself, so it survives a container recreate.

## Upgrading

No manual migration step. Pull the new image and restart:

```sh
docker compose pull && docker compose up -d
```
