# spoolbook v1.6.0 — safer sign-in, safer import

**Released**: 2026-10-16

MINOR: adds new capabilities — sign-in throttling, signing out other devices on a password
change, and a guard against importing the same export twice — plus fixes. Nothing breaking.

Spec coverage: 100% of surfaces, 91% of FRs tested (70% at planned layer).

## Added

- **Sign-in throttle.** After 5 wrong passwords for a username within 15 minutes, sign-in for
  that username pauses until 15 minutes have passed — even with the right password. The sign-in
  page says "Too many failed attempts. Try again in 15 minutes." A successful sign-in resets the
  count. (#179)
- **Password change signs out other devices.** Changing your password ends every other session,
  so a stolen cookie stops working; the device you changed it on stays signed in. Changing only
  the username doesn't sign anyone out. (#179)
- **Import once.** Each export is stamped with an id. Importing the same file a second time —
  or an install's own export back into itself — is refused with "This export has already been
  imported here", instead of duplicating spools, profiles and prints. Exports made before v1.6
  don't carry the stamp, so check the preview counts before importing one of those twice. (#160)

## Fixed

- **HTML markup in filament names.** Catalog filaments (all Bambu ones, for example) showed raw
  markup in their material and variant. New syncs clean it, and filaments already imported are
  repaired on start — renamed in place, or merged into the clean twin if one exists, with their
  spools and profiles moved over. (#209)
- **Delete refusals.** Deleting a filament, spool, project or printer that's still in use now
  says why, instead of failing silently. (#180)
- **Re-picking the import file.** Picking the same file again after an import now loads it
  again. (#180)
- Expired sessions are deleted whenever someone signs in, and abandoned Google sign-ins are
  dropped after 5 minutes, so neither piles up. (#179)

## For developers

- **Browser tests.** `npm run test:e2e` in `spoolbook-web-svelte` runs Playwright against the
  real backend on port 5070 with a throwaway database (first time: `npx playwright install
  chromium`); CI runs it as the `e2e` job. (#180)
- `POST /api/login` can answer `429 too_many_attempts`. `POST /api/import/preview` and
  `/api/import/commit` refuse a known bundle with `already_imported`. Export manifests now carry
  a `bundleId`.
- Migrations `0020` (`login_attempts`) and `0021` (`data_bundles`).

## Upgrading

No manual step — the migrations and the filament repair run on start. Pull the new image and
restart:

```sh
docker compose pull && docker compose up -d
```

Closes #209, #180, #179, #160.
