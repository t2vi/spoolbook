# spoolbook v0.1.5 — .3mf plate thumbnails on Prints

**Released**: 2026-07-26

---

## Highlights

- **Plate thumbnail preview on Add/Edit Print**: attach a `.3mf` project and spoolbook reads the plate thumbnail(s) straight out of the file's `Metadata/model_settings.config` — no re-slicing, no separate export. A `.3mf` can contain more than one build-plate layout; a Print always corresponds to exactly one, so a plate picker (`< n / total >`) lets you choose which one this Print used, with the first plate selected automatically so the preview never opens empty. Thumbnails are read fresh from the file each time, never cached or copied, matching the existing link-not-copy approach to Projects.
- **Save is blocked while thumbnails are loading**: reading a plate image out of the zip is async; the Save button (and the Save action itself) is disabled until it finishes, so a Print can't be saved with a plate selection that hasn't resolved yet.
- **Missing required fields highlight red**: Spool, Profile, Printer, and the Started/Ended date-time fields now outline in red on a failed Save, in addition to the existing error message, so it's obvious at a glance what's missing.
- **CalendarDatePicker for Started/Ended**: replaced the segmented date spinner with a compact text+calendar-popup picker — same information, less horizontal space.
- **Ambient column formatting fix**: the Prints table's Ambient column was printing Open-Meteo's raw humidity value at full floating-point precision (e.g. `83.66666666666666666666666667%`); it's now rounded to one decimal place.

## Upgrading

New nullable `Print.ProjectPlaterId` column (EF Core migration `AddProjectPlaterIdToPrint`) — applies automatically on next launch, no manual steps.
