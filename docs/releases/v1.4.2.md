# spoolbook v1.4.2 — live camera works on Docker

**Released**: 2026-08-29

PATCH: bug fixes only, no new capability.

## Fixed

- **Live camera feed failed on every Docker install** — the card showed *"Camera error / Camera
  stream failed — printer may be off or camera disabled"* even with the printer on and telemetry
  and printing working. The MJPEG relay shells out to `ffmpeg`, which wasn't in the runtime
  image (it only worked in local dev, where `ffmpeg` is on `PATH`). Now installed in the
  container. The image grows ~150MB.
- **The "Docs site" CI check was failing on every push to `main`** since 2026-08-26 — a
  job-level `if: ${{ hashFiles(...) }}` left by the template sync made the whole workflow file
  invalid (`hashFiles` isn't available there). Removed; the path filter on the trigger already
  scopes it.
- **"No live job data yet" while a print was running.** The MQTT client subscribed to the
  printer's status topic but never asked for a full status dump, so it only saw sparse delta
  messages (which omit the print state) until the printer's own slow periodic push. Now sends a
  `pushall` request on every connect — matters especially since telemetry starts the moment a
  printer is added, mid-print.

## Upgrading

No manual migration step. Pull the new image and restart:

```sh
docker compose pull && docker compose up -d
```
