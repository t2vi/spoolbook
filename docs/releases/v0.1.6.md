# spoolbook v0.1.6 — Self-hosted web app, printer control, live camera

**Released**: 2026-08-14

---

## Highlights

- **Self-hosted web app (`Spoolbook.Web`)**: spoolbook now runs as a Blazor Server app you host on your own LAN — reachable from a phone or any device on your network, not just the machine it's running on. The Avalonia desktop app keeps working against the same database in parallel. Gated behind a shared-secret login for anything that changes data; browsing stays open.
- **Live printer telemetry and control**: connects to your printer's own MQTT feed for real-time status, temps, and full per-slot AMS tray contents. Pause, resume, and stop a running print directly from spoolbook.
- **Send a print from spoolbook**: pick a `.3mf` project (upload, URL import, or a previously-linked one), a plate, and an AMS slot, and send it straight to the printer — no need to go through Bambu Studio/Handy first.
- **Live camera view**: see your printer's camera feed from its card, opened in a popup window.
- **One cohesive per-printer view**: the Printers page is now a full card per printer — status, controls, camera, AMS trays, and a "Recent prints" strip, instead of features scattered across separate pages. Sending a print now automatically creates its print-history entry (previously a separate manual step) and fills in its outcome (success/failed) automatically once the printer reports the job finished.

## Upgrading

Schema migrations run automatically on next launch. `Print.EndedAt` is now nullable and a new `InProgress` status exists for prints sent from spoolbook's send flow — no data loss, existing Prints are unaffected. To run the web app: set `SPOOLBOOK_ADMIN_PASSWORD` and start `Spoolbook.Web`; it uses the same SQLite database as the desktop app.
